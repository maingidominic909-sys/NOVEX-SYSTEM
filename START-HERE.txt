NORVEX INTEGRATED ENTERPRISES LTD — supply & procurement system (v2)
====================================================================

RUN THE SYSTEM
--------------
    node server/server.js          # → http://localhost:3000

No install needed (zero dependencies). Node 18+.

WHAT'S NEW IN v2
----------------
• One modern design system and ONE navigation shell on every page.
• A real homepage at /  (the old build 404'd here).
• All 18 pages connected: header nav + order-desk tab strip + mega footer.
• Brand-new sign-in / create-account panel with one-click demo accounts.
• Admin operations console + catalogue manager behind the admin role.
• Legacy links (Index.html, catalogue.html, supply-basket.html,
  future-order.html) redirect to the new pages.
