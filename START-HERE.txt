NORVEX INTEGRATED ENTERPRISES LTD — supply & procurement system
================================================================

WHAT'S IN THIS FOLDER
---------------------
norvex-app.html            ← THE APP. One self-contained file (nothing to install).
                             Open it in any modern browser and you are in.
norvex-v6-preview.html     ← screenshot tour of this round (basket, sign-out, buttons).
norvex-navigation-preview.html ← how the website and the console navigate.
norvex-mobile-preview.html     ← phone layouts.
norvex-analytics-preview.html ← admin money dashboard tour.
norvex-accounts-preview.html  ← sign in / sign up / catalogue manager tour.

SOURCE (for developers)
-----------------------
public/          the multi-page site: HTML, CSS, JS, images
data/            catalogue.json (13 departments, 45 products)
server/          zero-dependency Node API + session cookies
tools/           build-single-file.py  (rebuilds norvex-app.html)
                 pw-setup.sh           (installs the QA browser harness)
README.md / README-analytics.md       how it is put together

RUN THE MULTI-PAGE VERSION WITH THE API
---------------------------------------
    cd norvex
    node server/server.js          # → http://localhost:3000

REBUILD THE SINGLE FILE AFTER EDITS
-----------------------------------
    python3 tools/build-single-file.py

WHERE THINGS ARE
----------------
Browsing           free, no account needed
Sign in            menu → Sign in,  or  #/auth
Sign out           header avatar menu → Sign out
                   rail (bottom left) → ⏻
                   account page → Sign out
                   basket summary → Sign out
Place an order     needs an account (guest is returned to the review step)
Orders             #/orders
Basket             #/basket
Pay                #/checkout
Admin dashboard    #/admin          (money, profit, charts)
Catalogue manager  #/manage         (add / edit / delete products & departments,
                                     prices, pictures)
